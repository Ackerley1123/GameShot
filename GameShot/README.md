# GameShot 2.1 游戏库与截图工具

Windows 桌面工具：在游戏库中查看游戏时长、启动游戏、浏览截图；用全局快捷键截图，并按游戏或应用名称保存 PNG。源码关键逻辑有中文注释。

## 界面

2.1 采用简洁的苹果风视觉：柔和浅色背景、圆角卡片与输入框、蓝色主操作按钮，以及顶部导航。浅色为首次启动的默认主题；已有主题设置会保留。在“设置”页可以选择跟随系统、浅色或深色，再点击“保存设置”。

游戏库、截图、分类和设置共用同一套样式。键盘仍可通过 Tab 移动焦点，Enter / 空格点击按钮，Ctrl + Tab 切换页面；聚焦控件会显示蓝色边框。

## 游戏库

首页采用侧栏列表与封面卡片。支持搜索、深色与浅色主题，点击卡片进入游戏详情。

1. 点击“添加游戏”，填写名称和进程名。选择游戏 `.exe` 时会自动填入进程名；选择 `.lnk` / `.url` 快捷方式时，请填写实际游戏进程名。进程名可在任务管理器“详细信息”中查看，多个进程用逗号分隔。
2. 关联启动文件后，详情页的“启动游戏”会打开该程序或快捷方式。不关联启动文件也可以截图和统计时长。
3. 可选择自己的 PNG / JPG / BMP 封面。未设置时显示名称与渐变封面。常见游戏的预设分类不代表本机已经安装游戏。
4. 详情页显示累计游戏时长、前台时间、本次 GameShot 会话和最近游玩时间。截图缩略图点击打开原图，右键可定位文件或复制路径，也可以直接打开截图文件夹。

已有截图会按保存目录自动进入游戏库，普通软件的截图归档默认不计时。需要为其计时，点击“编辑游戏”关联实际进程即可。游戏改名后，历史时长及原目录的截图继续保留；文件留在原位置。

图库按最新时间排列，显示最近 120 张缩略图；更多图片可在文件夹中查看。“刷新截图”可以重新读取外部加入的图片。

## 时长记录方式

仅记录 **GameShot 开启期间** 检测到的游戏运行时间，不导入 Steam 历史时长。只需把 GameShot 留在托盘，不必从工具中启动游戏。

- 累计时长包含游戏在后台运行的时间。同一游戏的多个进程不会重复累计。
- 前台时间仅累计实际游戏窗口位于前台的时间。
- 本次会话从当前 GameShot 启动开始计算，重启工具后归零；累计时长保留。
- 锁屏及休眠期间暂停计时。进程每两秒检测一次，边界可能有约两秒误差。
- 大约每 15 秒保存一次，并在正常退出时保存；强制结束或断电可能丢失最近一次保存后的少量时间。

游戏库保存在 `data/library.json`，更新时保留上一份 `.bak`；封面复制到 `data/covers`。迁移到其他目录时请一起保留 `data` 和 `Screenshots` 文件夹。若截图保存到其他磁盘，请单独保留该目录。

## 启动与截图

双击本目录的 `GameShot.exe`。运行需要 Windows x64 和 .NET 10 Desktop Runtime；从源码编译还需要 .NET 10 SDK。

| 默认快捷键 | 截图方式 |
| --- | --- |
| F8 | 当前游戏 / 应用所在的显示器 |
| F9 | 框选区域，支持跨显示器 |
| F10 | 当前前台窗口的可见部分 |
| Ctrl + Shift + F8 | 全部显示器 |

框选时拖动鼠标，松开即保存；按 Esc 或鼠标右键取消。也可以用方向键移动选区，Shift + 方向键改变大小，Ctrl 加速，Enter 确认。

关闭或最小化主窗口后，工具仍在系统托盘运行。双击托盘图标打开窗口；右键托盘图标选择“退出”才能完全退出。再次启动程序会唤回已运行的实例。

## 按游戏分类

默认保存位置为程序旁的 `Screenshots` 文件夹，结构如下：

```text
Screenshots/
  原神/
    2026-10-08/
      20-15-32-108_屏幕_a19e03.png
  Counter-Strike 2/
    2026-10-08/
      20-20-05-612_窗口_b783f1.png
```

分类依据是截图触发时的前台进程。常见游戏已有预设名称；其他游戏先按进程名保存。普通软件也按各自的进程分类。

在“游戏分类”页填写“进程名 → 游戏名称”，然后点击“保存分类”。进程名可在任务管理器的“详细信息”中查看。先切换到游戏，再回到 GameShot，点击“添加当前进程”，可快速添加最近识别的游戏。

在“设置”页勾选固定分类并填写游戏名，可以让本次会话的截图始终归到同一个游戏。设置保存后立即生效；改名只影响后续截图，已有文件保留原位置。

目录名中的 Windows 禁用字符会替换为下划线，设备保留名会加前缀。文件名包含毫秒和随机后缀，连续截图不会覆盖已有图片。

## 设置

- 保存目录可改到其他磁盘或文件夹。
- 点击快捷键输入框后按新组合键，支持 Ctrl、Alt、Shift；按 Tab 切换输入框。编辑期间截图快捷键暂时停用。
- 快捷键若被其他程序占用会显示错误，并恢复旧设置。F12 是系统保留键，不可选用。
- 可以启用截图通知、自动复制图片到剪贴板，选择浅色、深色或跟随系统主题。
- 主窗口列出本次运行最近的截图，双击打开图片，或选择“在文件夹中查看”。

配置保存在程序旁的 `data/settings.json`。截图保存在本地，工具不上传图片、不注入游戏、不修改游戏文件，也不默认添加开机启动。

## 捕获兼容性

优先使用 Windows DirectX Desktop Duplication，按显示器所属显卡读取桌面帧。首个空白帧会丢弃，等待有效桌面帧。DirectX 不可用时自动回退到普通桌面捕获，并显示提示。两种方式都保存无损 PNG。

适用于普通 Windows 界面和多数游戏。无法承诺所有界面：系统安全桌面、受 DRM / 捕获保护的内容，以及部分独占全屏或特殊驱动模式可能无法捕获。黑图提示不会删除文件；游戏黑图时可尝试无边框窗口模式。管理员权限运行的游戏若快捷键无响应，可用相同权限启动 GameShot。

窗口截图读取当前屏幕中可见的窗口区域；不捕获最小化窗口，也不会还原被其他窗口遮住的内容。多显示器组合不是同时曝光，快速运动画面可能存在少量时间差。本机验证使用单显示器、150% 缩放；旋转屏和多显卡布局已实现，但尚未实机验证。

## 源码与编译

使用 C#、.NET 10 和 Windows Forms；源码位于 `src/`，关键逻辑有中文注释，没有第三方运行依赖。

| 文件 | 用途 |
| --- | --- |
| `Program.cs` | 启动、单实例、托盘窗口唤回 |
| `MainForm.cs` | 界面、设置、快捷键与截图流程 |
| `DesktopDuplication.cs` | 显卡枚举、有效帧读取、GPU 纹理复制及资源释放 |
| `Capture.cs` | 多屏合成、普通捕获回退、黑图检测 |
| `RegionSelector.cs` | 画面冻结、鼠标及键盘框选 |
| `Models.cs` | 配置、前台进程识别、游戏分类和 PNG 归档 |
| `GameLibrary.cs` | 游戏库保存、进程检测、运行与前台时长统计 |
| `LibraryView.cs` | 游戏列表、搜索、卡片、启动与截图图库 |
| `LibraryArtwork.cs` | 封面绘制、缩略图及图片资源释放 |
| `GameEditDialog.cs` | 添加或编辑游戏、启动文件和封面 |
| `Appearance.cs` | 统一配色、圆角按钮、线条图标、输入框和顶部导航 |
| `Native.cs` | Windows 系统接口 |
| `SelfTests.cs` | 实际桌面色块、PNG 及全局快捷键集成验证 |
| `LibraryTests.cs` | 时长去重、锁屏恢复、保存恢复、改名与分类拆分验证 |

安装 .NET 10 SDK 后，在本目录运行：

```powershell
.\build.ps1
# 包含真实桌面截图和键盘消息的集成测试：
.\build.ps1 -Test
# 不抢占前台，只验证游戏库和时长记录：
.\build.ps1 -TestLibrary
```

输出为 `release/GameShot.exe`，脚本同时复制到本目录。复制到其他电脑使用时需要 .NET 10 Desktop Runtime（x64）。

测试结果在 `tests/results/test-report.txt`，测试图片仅保存测试窗口及其裁切，不保存整个桌面。测试会短暂激活色块窗口并恢复原前台窗口。

完整捕获测试要求测试色块窗口位于前台。若其他游戏持续占用前台，测试会报告前置条件失败，请在桌面空闲时重试。游戏库独立测试不会抢占前台，结果为 `tests/results/library-test-report.txt`。

2.1 已检查 150% 缩放下的浅色、深色、游戏详情、截图图库、截图、分类与设置页面，时长和图库回归检查通过。测试输出仅保存在运行测试的电脑上，不包含在源码仓库中。游戏启动需自行关联实际安装的本地游戏路径。
